# Stop And Error

`neuroflow.stopAndError` (v1) -- flow/Core

Stops the workflow and reports a custom error message.

**Aliases:** throw, fail, abort

## Ports

- **Inputs:** main
- **Outputs:** none

## Properties

| Name | Display Name | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `message` | Error Message | string | Yes | Message reported as the node's error. |
